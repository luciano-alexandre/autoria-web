Como a Web funciona

A Internet é a infraestrutura que conecta redes e dispositivos. A Web é um serviço que usa essa infraestrutura para disponibilizar páginas e outros recursos.

  1. O usuário digita uma URL no navegador.
  2. O DNS localiza o endereço do servidor.
  3. O cliente envia uma requisição HTTP ao servidor.
  4. O servidor responde e o navegador apresenta a página.

A URL identifica o recurso, o DNS encontra o servidor e o HTTP define a comunicação entre o cliente — o navegador — e o servidor.

Boas práticas

Cuidados ao produzir uma página

  • Use elementos HTML de acordo com o significado do conteúdo.
  • Escreva textos de links claros e mantenha contraste adequado.
  • Organize e indente o código de maneira consistente.
Atenção: não use títulos apenas para aumentar o tamanho do texto; preserve a hierarquia do conteúdo.
